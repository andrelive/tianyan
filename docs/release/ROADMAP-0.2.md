# 天演 0.2 路线图（Roadmap）

> 计划版本：0.2.0 · 状态：规划中

0.1 已发布并稳定使用（轻量任务可用）。以下为 0.2 计划功能，按优先级排序。

## 1. Web 搜索后端 UI 配置入口

- **现状**：`[web] search_backend`（duckduckgo/bing/searxng）只能改配置文件，UI 无入口。
- **计划**：设置页/配置向导加 Web 配置步骤（后端选择 + SearXNG 端点）。
- **背景**：国内默认 duckduckgo 不可达，需手动改配置为 bing。

## 2. 数据目录搬迁功能

- **现状**：数据默认存 C 盘（AppData\Local\tianyan），只能手动移动 + 改配置。
- **计划**：设置页"数据目录搬迁"——选新目录 → 确认 → 程序自动完成（关 DB → 移动 → 更新配置 → 重启）。
- **技术点**：SQLite/LanceDB 关闭机制（释放文件锁）、Tauri 重启协调、失败回滚。

## 3. Todolist 功能

- **计划**：任务列表管理（创建/完成/删除/优先级），供用户跟踪多步任务。

## 4. Goal 目标功能

- **计划**：目标管理（长期目标 + 进度跟踪），与 todolist 配合。

## 其他候选

- 自动更新发布流水线恢复（GitHub Actions 免费额度）
- 会话内规则/记忆刷新（ADR-012 缓存优先的实时性权衡）
- 多智能体角色扩展（PPT/办公等专业子智能体）
- 任务面板区分"内置任务/后台任务"（对齐 DSH 界面：内置与后台分开展示）

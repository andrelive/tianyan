7. 核心模块速览

agent

core/src/agent/

AgentCoordinator + AgentLoop + ToolRegistry（14 个内置工具）+ AgentBuilder。LLM 自主工具调用、流式响应、澄清问题、子 Agent 委托。

vfs

core/src/vfs/

虚拟文件系统 — 统一存储与检索抽象层。L0/L1/L2 三层内容 + SummaryEngine 摘要生成 + LanceDB 向量化 + RRF 融合检索。

context

core/src/context/

上下文工程 — ContextAssembler（前缀匹配组装）+ ContextPipeline（检索 + 压缩）+ DualLayerRetriever（双层检索）。

knowledge

core/src/knowledge/

知识库导入管道 — KnowledgeIngestor + 文档解析器（PDF/DOCX/MD/CSV/XLSX）+ 图片处理（EXIF/VLM）+ 向量化写入 VFS。

memory

core/src/memory/

MemoryExtractor — LLM 驱动的长期记忆提取。Pattern / FailedCase 分类，提取后写入 VFS，Scheduler 定时触发。

skills

core/src/skills/

技能系统 — 6 个内置技能（文件操作、HTTP 请求、系统命令）+ GEPA 进化引擎自动学习 + 渐进式披露（L0→L2）。

session

core/src/session/

PersistentSessionManager — JSONL 文件持久化会话。StructuredMessage 单一真相源，压缩标记，实时写入。

model

core/src/model/

ModelServices 容器 — ChatService + EmbeddingService + VlmService。async-openai 实现，OpenAI 兼容，不路由不重试。

scheduler

core/src/scheduler/

定时任务调度 — RuleTask（规则提炼）+ MemoryTask（记忆提取）+ SummaryTask（摘要生成）+ GcTask（垃圾回收）。

executor

core/src/executor/

工具执行支撑 — Action 执行 + 安全审批（风险等级）+ LLM-as-Judge 评估 + VerificationGate 验证门控。

observability

core/src/observability/

AgentMetrics 可观测性存储 — 执行追踪、管线失败计数、规则命中率统计、规则注入追踪。

config

core/src/config/

全局配置管理（12 个子文件）— TOML + 环境变量，查找顺序：./tianyan.toml → ~/.config/tianyan/ → ~/.tianyan/。
